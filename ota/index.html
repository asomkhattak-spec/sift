Update service

The quiet endpoint behind Sift.

Sift checks this service once per launch. It carries a small interface bundle and release information — data only, never code. There are no ads here, and no visitor account.

What can change remotely

  • Accent colour, tagline, home-screen starters, and whether the shortcut and privacy cards appear.
  • The interface bundle cannot add code, change search settings, or send your queries anywhere. Turning interface updates off restores the copy built into the app.
  • App releases are APKs attached to a public GitHub release. Sift checks the SHA-256 digest before Android's installer is opened, and Android still asks for your confirmation.
