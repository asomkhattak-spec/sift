Image and video results are now first-class.

- Images fill a responsive grid from Openverse, Wikimedia Commons, and other sources, with attribution and licence details kept beside the work.
- Videos show posters, duration, creator, and source; Commons video is filtered by MIME type so audio files stay out.
- The image viewer supports swipe, pinch and double-tap zoom, download, share, and opening the source in an in-app tab.
- Search keeps local matches above web results, and every provider now has its own timeout.
- New: optional interface bundles and checked APK updates. The app validates both, installs nothing silently, and Android always asks first.

Sift still has no ads, no account, and no query profile. Web sources still receive the requests you send to them.
